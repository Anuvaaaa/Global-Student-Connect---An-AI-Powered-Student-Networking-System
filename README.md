# Global-Student-Connect---An-AI-Powered-Student-Networking-System
Global Student Connect is a web-based platform designed to help university students connect with peers based on shared interests and hobbies. The platform aims to simplify communication among students around the world while providing AI assistance.

# Global Student Connect

Global Student Connect is an AI-powered student networking system that helps university students connect based on shared interests, hobbies, language, university, and country.

## Features
- Google OAuth login
- Student verification
- Profile management
- AI-based matching
- Moments feed
- Messaging system
- AI translation
- Notifications
- Missions and badges
- AI safety agent

## Technology Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Django
- Database: MySQL
- Authentication: Google OAuth
- Version Control: Git and GitHub
